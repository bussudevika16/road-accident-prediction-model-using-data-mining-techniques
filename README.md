# Road Accident Prediction Model Using Data Mining Techniques

Predict road accidents using Data Mining & Machine Learning.

**Tech Stack:** Python, Django, Pandas, Scikit-learn, Random Forest, SVM, Decision Tree

**Problem:** Weather, Road Surface, Lighting, Vehicle Type valla accident avthundo ledho mundhe telusukovadam kashtam.

**Solution:** Historical accident data tho train chesina ML model, Accident / No Accident ani predict chesthundi.

**Features:**
- User Registration & Login
- Accident Prediction Form
- Accuracy Graph & Prediction Ratio
- Admin Dashboard to View All Predictions
